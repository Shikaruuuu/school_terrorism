# 学校にテロリスト

5時間目の授業中、中学校にテロリストが入ってきた――。掃除用具ロッカーに隠れた中学2年生・ユウトを操作する、ブラウザで遊べる3Dステルスアクションです。

## 遊び方

`index.html` をブラウザで開きます（スマホは横向き推奨）。ローカルで開く場合は、次のように簡単なサーバーを立てると確実です。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## ストーリー

- **1人で脱出編**：見つからずに学校を抜け出し、警察へ駆け込む
- **好きな子を救え**：音楽室に捕まった白石さんを助け出し、2人で脱出する
- **テロリストを倒せ**：仲間を解放しながら、テロリストを全員倒す

それぞれ「かんたん・ふつう・むずかしい」の難易度があります。

## 操作

- スマホ：左のスティックで移動、右のボタンで殴る・しゃがむ・走る、画面右側のドラッグで視点
- PC：WASD 移動、Shift 走る、E 殴る、C しゃがむ、マウスで視点

## 構成

- `index.html`：画面とスタイル
- `js/map.js`：校舎のマップ、敵の配置、ストーリーと難易度の設定
- `js/world.js`：マップから3Dの校舎を組み立てる
- `js/models.js`・`js/characters.js`：アイテムや人物の3Dモデル
- `js/game.js`：ゲーム本体（敵AI、操作、カメラ、画面表示）
- `js/audio.js`：効果音とBGM（WebAudioで合成）
- `vendor/three.min.js`：Three.js r160（MITライセンス、`vendor/three.LICENSE`）

本作はフィクションです。登場する学校・人物・団体はすべて架空のものです。
