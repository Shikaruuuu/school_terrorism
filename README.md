# 〇〇にテロリスト

いつもの場所が突然テロリストに占拠された――。敵に見つからずに大切な人を探し出して助け、2人で生きて脱出する、ブラウザで遊べる3Dステルスアクションのシリーズです。

## 遊び方

`index.html` をブラウザで開きます（スマホは横向き推奨）。ローカルで開く場合は、次のように簡単なサーバーを立てると確実です。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## ステージ

共通ルールは「女の子を探す → 助ける → 2人で脱出」。居場所は遊ぶたびに変わり、オープニングの一言・目的欄の手がかり・近くに落ちている持ち物が目印です。助けた後は女の子にも体力があり、どちらかが倒れるとゲームオーバー。

- **学校にテロリスト**（情報を集める）：5時間目の授業中に中学校が占拠される。校内に隠れているクラスメートに近づいて「話す」と、白石さんが連れていかれた方角・場所・特徴を1つずつ教えてくれる（実際の居場所と必ず一致）。聞いた話が重なる範囲がレーダーと地図に出る。話している間は動けず、ひそひそ声はすぐ近くの敵に聞こえる。全員に聞かなくてもクリアできる。白石さんを見つけると、立ち絵つきの会話になる。助けたあとはクラスメートに話しかけると裏門の鍵のありかを教えてくれるので、鍵を手に入れて2人で脱出
- **ショッピングモールにテロリスト**（ルートを選ぶ）：デート中に2階建てのモールが占拠される。遊ぶたびに、出口・エスカレーター/非常階段・通路・店のシャッターのどこかが封鎖される。店の表と裏口（バックヤード）を抜ける、別の階を回るなど、そのときの封鎖に合わせてルートを考える。美咲を助けると、いちばん近い出口と通路がさらに閉まるので、帰り道も選び直しになる。どの組み合わせでも救出と脱出ができること、敵の見回りが詰まないこと、大回りになりすぎないことを確かめた封鎖だけを使う

それぞれ「かんたん・ふつう・むずかしい」の難易度があります。クリアすると、見つかった回数・時間・受けたダメージ・難易度から総合ランク（S／A／B／C）が付きます。

## 操作

- スマホ：左のスティックで移動、右のボタンで殴る（人の近くでは話す）・しゃがむ・走る、画面右側のドラッグで視点、レーダーをタップで全体マップ
- PC：WASD 移動、Shift 走る、E 殴る・話す、C しゃがむ、M 全体マップ、マウスで視点

## 構成

- `index.html`：画面とスタイル
- `js/map.js`：ステージ「学校」（校舎のマップ、敵の配置、物語・人物）と難易度の設定
- `js/gfx.js`：描画の仕上げ。空・霧・環境光（反射）・主人公のまわりの影・近くの照明だけ本物の光にする光源プール・ポスト処理（ブルーム、ACESトーンマップ、色調補正、ビネット、警戒/危険/会話中の画面効果）。画質「高・標準・軽量」の切り替えと、重いときに描画解像度を自動で下げる仕組み
- `js/materials.js`：画像ファイルを使わずキャンバスで作るPBRの質感（しっくい・リノリウム・木の床・タイル・テラゾー・コンクリート・金属・布など）。ワールド座標で貼るので伸びない
- `js/world.js`：マップから3Dの校舎を組み立てる（夕方の校舎：夕日の差し込む窓と光の筋、蛍光灯、机と椅子、黒板、掲示物、部屋ごとの小物）
- `js/mall.js`：ステージ「ショッピングモール」（2階建てのマップと3D、敵の配置、物語・人物）
- `js/models.js`・`js/characters.js`：アイテムや人物の3Dモデル
- `js/game.js`：全ステージ共通のゲーム本体（敵AI、経路探索、操作、カメラ、画面表示）

新しいステージは `TG.STAGES` に登録します（`js/mall.js` が例）。2階建ては、2階をグリッド上で横にずらして並べ、階段の端の「ポータル」のマスでつなぐ仕組みです。
- `js/audio.js`：効果音とBGM（WebAudioで合成）
- `js/cast.js`：会話に出る人物（名前・色・表情ごとの立ち絵）の一覧と、敵の一言
- `assets/chars/`：会話用の立ち絵（`<人物>_<表情>.webp`、縦3:4）。画像のない人物は人物の色のシルエットカードで表示する
- `docs/character_prompts.md`：立ち絵を画像生成AIで作るためのプロンプトとファイル名の一覧
- `tools/optimize_portraits.py`：作った立ち絵を600×800のWebPにそろえて `assets/chars/` に入れる
- `vendor/three.min.js`：Three.js r160（MITライセンス、`vendor/three.LICENSE`）

本作はフィクションです。登場する施設・人物・団体はすべて架空のものです。
