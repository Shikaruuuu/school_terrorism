# 〇〇にテロリスト：会話用キャラクター画像の生成プロンプト

このセッションには画像を生成する手段がないため、白石さん以外の画像はまだありません。
ゲーム内では、画像がない人物は**人物ごとの色のシルエットカード**で代わりに表示しています。
下のプロンプトで ChatGPT（画像生成）または Gemini に画像を作ってもらい、
指定のファイル名で `assets/chars/` に置けば、ゲームが自動で読み込みます（コードの変更は不要）。

---

## 1. 全キャラ共通の画風指定（各プロンプトの先頭に必ず付ける）

```
リアル寄りの美麗な3Dゲームキャラクターの立ち絵。最新の家庭用ゲーム機のカットシーンのような質感。
実在の人物の写真ではなく、架空のゲームキャラクターとして描く。アニメ調・漫画調・ローポリゴン調にはしない。
構図：胸から上のバストアップ。カメラは正面〜斜め45度以内。顔が画像の上から3分の1あたりに来るようにする。
照明：映画的で自然なライティング。夕方の校舎や館内の非常灯を思わせる、暖色のキーライトと弱いリムライト。顔と表情がはっきり見えること。
背景：無地に近い暗めのグレー〜紺のぼかし背景（被写界深度で背景はぼかす）。
画像内に文字・名前・セリフ・ロゴ・透かしを一切入れない。1枚に1人だけ。コラージュにしない。
縦長 3:4（768×1024 ピクセル）。
```

### 表情差分を同じ人物で作るコツ

1. まずその人物の「1枚目（基本の表情）」を作る。
2. 2枚目以降は、1枚目の画像を添付して次のように頼む：
   `添付画像と完全に同じ人物・同じ髪型・同じ服装・同じ構図・同じライティングのまま、表情だけを「〇〇」に変えてください。文字は入れないでください。`
3. 白石さんの画風に合わせたいときは、既存の白石さんの画像（`assets/chars/shiraishi_normal.webp`）も参考画像として添付し、
   `この画像と同じ画風・質感・ライティングで` と付け加える。

## 5. 画像を組み込む手順

1. 作った画像（PNG・JPG・WebP どれでも可）を、上の表のファイル名（拡張子は何でもよい）で1つのフォルダに入れる。
2. 次のコマンドで、600×800 の WebP に縮小・圧縮して `assets/chars/` に保存する（1枚 30〜60KB 程度になる）。
   ```sh
   python3 tools/optimize_portraits.py <画像のフォルダ>
   ```
3. ゲームを開き直すと、シルエットカードの代わりに画像が出る。一部の表情だけ置いた場合は、同じ人物のほかの表情で代わりに表示する。

人物と表情の一覧（ファイル名の元）は `js/cast.js` にあります。会話の行では `{ who: 'teacher', face: 'panic', t: '…' }` のように指定しています。
