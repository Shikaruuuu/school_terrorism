# 3D アセット（GLB / glTF）の作り方と差し替え手順

ゲームの家具・人物は、今はすべてコードで作った形（手続き生成）です。
`js/assets.js` の一覧（MANIFEST）に GLB を登録すると、その形に差し替わります。
登録していない、または読み込みに失敗したときは、今まで通りコードの形が使われます（ゲームは止まりません）。

## 1. 差し替えのしくみ

| 種類 | ID の例 | 差し替わる場所 | 使う関数 |
|---|---|---|---|
| 家具 | `school/desk` `school/chair` `school/teacher_desk` `school/cleaning_locker` | 普通教室キット（`js/kit_classroom.js`） | `TG.assets.instanced()` |
| 人物 | `char/shiraishi` `char/student` など | その人物のモデル全員 | `TG.models.withAsset()`（`js/characters.js`） |

- 当たり判定・移動・イベントの位置は、マップのマス（`js/map.js` / `js/mall.js`）だけで決まります。形を差し替えても、通れる場所は変わりません。
- 家具は 1 マス（1m×1m）に収まる大きさにしてください。はみ出すと、通れる場所に見た目がかぶります。

### 登録のしかた

`js/assets.js` の MANIFEST で、`null` を設定に書き換えます。

```js
'school/desk': { url: 'assets/models/school/desk.glb' },
'char/shiraishi': {
  url: 'assets/models/chars/shiraishi.glb', scale: 1, yaw: 0,
  clips: { idle: 'Idle', walk: 'Walk', run: 'Run', crouch: 'Crouch', crouchWalk: 'CrouchWalk', sit: 'Sit', down: 'Down' },
},
```

GLB は `assets/models/` の下に置きます。`index.html` を変える必要はありません。

## 2. 共通の決まり

- 単位はメートル。+Y が上、+Z が正面（glTF の標準）。
- 原点：家具は床面の中心、人物は両足の間。
- 材質：glTF の PBR（metallicRoughness）。ベースカラー・ラフネス/メタルネス・法線マップ。AO は任意。
- テクスチャは 1 枚 1024px 以下（スマホでは 512px 相当まで落ちても読める作りに）。KTX2 は今は未対応、PNG/JPEG/WebP を使う。
- ファイルは 1 つの GLB に埋め込み（外部テクスチャを参照しない）。

### 予算（Intel MacBook Pro 2020・8GB で 30fps を目標）

| 物 | 三角形 | 材質の数 | テクスチャ |
|---|---|---|---|
| 机・椅子（1つ） | 〜1,500 | 〜3 | 512px |
| 教卓・ロッカー | 〜3,000 | 〜3 | 1024px |
| 主人公・白石さん・美咲 | 〜15,000 | 〜4 | 1024px |
| 敵・生徒・客（同時に多数） | 〜6,000 | 〜2 | 512px |

机と椅子は 1 教室に 12 組ずつ、インスタンス描画で並べます（部品ごとに描画 1 回）。
人物は 1 体ずつ描くので、部品（メッシュ）を少なくまとめてください。

## 3. 人物モデルの条件

- リグ付き（スキンメッシュ）。骨の名前は自由（アニメーションと同じファイルに入れるため）。
- アニメーション名を `clips` に書く。足りないものは近いもので代用します：
  `crouchWalk → walk`、`run → walk`、そのほか → `idle`。
  - `idle` 待機、`walk` 歩き（1.4m/秒前後）、`run` 走り（3.5m/秒前後）、`crouch` しゃがみ待機、`crouchWalk` しゃがみ歩き、`sit` 床に座る（人質）、`down` 倒れる（1回だけ再生して止まる）
- 身長：中学生 1.55〜1.65m、大人 1.65〜1.80m。
- 顔の向きは +Z。足は原点の高さ（y=0）。
- 同じ GLB から何体も作るので、1 体あたりの読み込みは 1 回だけ（バイト列を使い回して組み立て直す）。

## 4. 権利（ライセンス）の決まり

- 使ってよいもの：自作のもの、CC0、または商用利用可で再配布できるライセンスのもの。
- 使わないもの：権利が分からないもの、ゲームなどから抜き出したもの（リッピング）。
- 外部のアセットを入れるときは、このファイルの末尾に「ファイル名・作者・入手元 URL・ライセンス」を書き足す。

### 今入っているもの

| ファイル | 内容 | 権利 |
|---|---|---|
| `vendor/three.min.js` | three.js r160 | MIT |
| `vendor/GLTFLoader.js` | three.js r160 の GLTFLoader を、モジュールでない読み込み用に書き換えたもの | MIT |
| `js/kit_classroom.js` ほか | 机・椅子・教卓などの形と、木目・塗装などの絵 | このゲームのために作ったもの（コードで生成） |

GLB のモデルは、今はまだ 1 つも入っていません。差し替えの動作は、テストのときだけ Khronos の glTF サンプル（CesiumMan・BoxTextured）を割り込ませて確かめました（配布物には含めていません）。

## 5. 普通教室キットの中身（`js/kit_classroom.js`）

1年A組・2年A組・2年B組・3年A組の 4 室に使っています。

- 机：角を丸めた化粧板の天板（厚み 2.4cm）、縁の樹脂テープ、角パイプの脚と幕板、鉄板の物入れ、足掛け、脚キャップ、かばん掛け
- 椅子：くぼませた成形合板の座面、湾曲した背もたれ、曲げパイプの脚、横桟、脚キャップ。14% は倒れている
- 教卓（前板の化粧パネル・棚板・台輪）、黒板（アルミ枠・粉受け・チョーク・黒板消し）、学級目標、時計、スピーカー、テレビ
- 窓：奥行きのあるサッシ、引き違いの 2 枚のガラス、窓台、カーテンレールとひだのあるカーテン
- 腰板・笠木・幅木、細いフローリング、化粧石こうボードの天井、2 灯の蛍光灯器具
- 後ろの作り付けの棚とかばん、コルクの掲示板と掲示物、掃除用具ロッカー（通気口・取っ手）
- 小物：教科書・ノート・筆箱・机に掛けたかばん・床に落ちたプリント
- 接地感：机・椅子・ロッカーの下の柔らかい影、床と壁・天井と壁の境目の影
- 遠くの教室は描かない（カメラから 12m 以内だけ）

## 6. ほかの場所への広げ方（予定の順）

1. 理科室：実験台（天板・流し・ガス栓）、丸椅子、薬品棚（ガラス戸）
2. 体育館・倉庫：床のライン、跳び箱・マット・ボールかご
3. 廊下・昇降口：下駄箱、消火栓、掲示板、床の継ぎ目
4. モール 1 階・2 階：店の棚と商品、ベンチ、植え込み、手すり、床の石の目地。白い床と照明パネルの白飛びを抑える

それぞれ「キットのファイルを 1 つ作る → world.js / mall.js の古い箱をその部屋だけ止める → 前後の写真と描画数を比べる」の順で進めます。

## 7. 実機での計測

URL の末尾に `?fps` を付けると、左上に次のものが出ます。

- フレームレート（1 秒の平均）、1 フレームの平均時間と 95% の時間
- 描画の回数（calls）と三角形の数（tris）
- 画質（high / mid / low）、画素の倍率、動的解像度（重いと自動で 60% まで下がる）
